Glacier Ref

An offline reference board: collect images and notes on an endless canvas next to the tools you work in. Glacier Ref never connects to the internet.

Menus

  • Press Tab to show or hide the menu bar, or click ≡ in the top-left corner of the canvas.
  • Right-click anywhere for the commands that fit what you clicked.
  • Every command has a keyboard shortcut you can change in Edit ▸ Preferences ▸ Shortcuts.

Adding images

  • Drop image files or folders onto the canvas, paste an image (Ctrl+V), or use File ▸ Import Images… (Ctrl+I).
  • Supported: PNG, JPEG, WebP, BMP, GIF and TIFF (first frame or page), and SVG.
  • File ▸ Import as Link… (Ctrl+Shift+I) keeps the image as a file on disk instead of copying it into the board.
  • Web addresses are not downloaded: save the image first, then drop the file.

Moving around

  • Pan with the middle mouse button, Space + drag, or two fingers on a touchpad.
  • Zoom with the mouse wheel or a pinch, at the cursor. F fits the board, Shift+F the selection, Ctrl+0 is 100%.

Editing

  • Click to select, Shift+click to add, drag on empty canvas for a selection rectangle.
  • Drag to move. Drag a corner or edge handle to resize (Shift: stretch), the round handle to rotate (Shift: 15° steps).
  • C crops the selected image (Enter applies, Escape cancels). H and V flip.
  • Ctrl+G groups, Ctrl+Shift+G ungroups; double-click a group to edit inside it, Escape leaves it.
  • Ctrl+L locks items so they can't be changed by accident.
  • N adds a note; double-click a note to edit it. While you type, keys go to the note; Escape finishes.
  • G shows images in grayscale. Everything can be undone with Ctrl+Z and redone with Ctrl+Shift+Z.

Boards and files

  • Ctrl+S saves the board as one .glacierref file that contains its images, so you can move it to another computer.
  • Linked images are stored relative to the board where possible. If one goes missing, it shows as a placeholder: select it and use Board ▸ Links to locate, reload or embed it.
  • A board that is open in another window or program opens read-only; use Save As to keep changes.
  • Unsaved changes are kept safe every minute. If Glacier Ref closes unexpectedly, the next start offers to recover them.

Windows

  • Ctrl+N opens another window with its own board.
  • View ▸ Frameless Window hides the title bar: drag the top edge (or Alt+drag) to move, the edges to resize. Right-click ▸ Show Window Frame brings it back.
  • View ▸ Always on Top asks the system to keep the window above others. Some desktops (for example KDE on Wayland) decide this themselves; use the window menu (Alt+F3) ▸ More Actions ▸ Keep Above Others there.
