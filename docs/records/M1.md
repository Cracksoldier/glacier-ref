New suites: `tst_affine2d`, `tst_boarddocument`, `tst_sessionassetstore`, `tst_imageprobe`, `tst_svgvalidator`,
`tst_batchlayout`, `tst_mimerouter`, `tst_importservice`, `tst_imagecache`, `tst_boardview`; `tst_mainwindow` extended with an end-to-end drop import.

Evidence for the completion criteria:

- **Formats, orientation, transparency:** `tst_imageprobe` covers all seven formats, EXIF orientation 6 for JPEG/TIFF (via Qt) and PNG/WebP (own parser), alpha in PNG/WebP/TIFF, and Display P3 → sRGB.
- **Cancellation and closing:** `tst_importservice` cancels mid-batch (finished images kept) and destroys the service while jobs run (ASan clean). Results carry the document token, and stale batches are discarded.
- **Unsupported input, no network:** a crafted PSD (rejected even with kimageformats installed), svgz, a 50000² header, truncated and zero-byte files, and 24 rejected SVG constructs; plus the offline audit of a full stress import (`docs/OFFLINE_AUDIT.md`).
- **No full-resolution retention:** the decoded cache stays within its 512 MiB budget for 300 × 2048² images (4.8 GB if fully decoded); see below.

## Performance baseline (M1.11)

Reference workstation (spec §9) under the constrained profile `tools/perf/run-constrained.sh`; constraints verified (`Cpus_allowed_list: 0-7`, `memory.max` 16 GiB, swap 0).
Offscreen platform at 2560×1440 (viewport 2560×1418), Release build, warm OS file cache, 300 frames per pass.
Datasets: `glacier-fixturegen --seed 1`. Standard: 300 × 2048² JPEG (~890 KB each, 256 MB). Stress: 1,000 mixed (668 MB; 429 JPEG including five 48 MP, 170 PNG, 154 WebP, 103 SVG, 85 BMP, 59 TIFF).
Frame time is the duration of a synchronous viewport repaint (CPU raster paint cost), not compositor latency.

## Observations and limitations

- Qt 6.12 does not apply EXIF orientation for PNG `eXIf` or WebP `EXIF` chunks; Glacier Ref parses them itself.
- Qt 6.12's TIFF and WebP handlers are order-sensitive (`imageCount()` vs `transformation()`/`size()`); a separate reader counts frames.
- Qt 6.12 cannot read back its own lossless WebP encoding of a uniform 8×8 image (36 bytes). The import fails cleanly with an error; this is a degenerate case.
- Qt cannot write GIF, so the stress dataset has no GIFs; GIF decoding (single and animated) is covered by crafted test fixtures.
- Items cannot be moved or deleted yet, and there is no undo (M2). Import has no placeholders; a progress dialog is shown instead.
- Always on Top is experimental: it sets the window hint and, on Wayland, explains that the compositor decides. The honest capability status comes in M4.
- The benchmark measures CPU paint cost offscreen. A full-screen run on the real Wayland output is part of the M1.12 checklist.
