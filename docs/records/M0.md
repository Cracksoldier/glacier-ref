### First CI run

[Run 42293061833](https://github.com/Cracksoldier/glacier-ref/actions/runs/42293061833)
(commit `d9b86fd`):

| Job | Result |
| --- | --- |
| Linux (ci-release) | success |
| Linux (ci-asan) | success |
| macOS (arm64) | success |
| Windows (MSVC, debug/release) | failure in *Install Qt* |

Cause, reproduced locally: aqtinstall 3.3.0 (the latest release) expects
`windows_x86/desktop/qt6_6120/qt6_6120/Updates.xml`, but Qt's online repository
now splits Windows releases into per-architecture folders
(`qt6_6120_msvc2022_64/`, …). Qt 6.11.3 fails the same way; Linux and macOS
still use the old layout. Upstream PR miurahr/aqtinstall#1048 (open) covers
other Qt 6.12 repository changes.
