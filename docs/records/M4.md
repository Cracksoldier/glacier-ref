## What M4 adds

- **Minimal UI (M4.01):** the menu bar starts hidden and Tab toggles it, remembered for all windows. A ≡ button offers the whole menu, context menus start with Show Menu Bar, and a one-time hint explains this. Help: offline basics, a shortcut reference generated from the live actions, About, Project Website (only on click), Copy Diagnostics.
- **Preferences (M4.02):** recovery interval and budget, image cache size (live), data folders, portable-mode status; Glacier dark or system theme (live), new-board background; every shortcut with alternate, conflict reporting that blocks OK, defaults per row and for all.
- **Window integration (M4.03):** size and state of the last window; Always on Top reports "on" only where the platform honours it and "requested — your compositor decides" on Wayland; Window Opacity, hidden on native Wayland.
- **Frameless mode (M4.04):** grip band, Alt+drag, edge and corner resize, all through `QWindow::startSystemMove/Resize`; four ways back.
- **DPI and input (M4.06):** canvas, window and link suites also run at `QT_SCALE_FACTOR=1.5`; Unicode paths with spaces; no canvas shortcuts while typing in dialogs.
- **Diagnostics (M4.09):** `glacier.*` categories, redaction of home and user name, stderr plus a capped log per process; opens and saves are logged by file name only.

New or extended suites: `tst_settings`, `tst_diagnostics`, `tst_platformwindow`; `tst_mainwindow` (menu toggle and ≡ button, first-run hint, help and website opener, diagnostics redaction, shortcut changes in every window, Preferences conflicts, live cache budget, theme switching, new-board background, geometry, opacity, honest always-on-top, frameless mode and its ways back, Unicode paths, dialog focus, one selection signal for many items); `.scaled` runs of `tst_boardview`, `tst_mainwindow` and `tst_links`.

Bugs found and fixed:
- **Crash when an open finished during a progress update** (found by the extended benchmark under ASan): a window-modal `QProgressDialog` runs a nested event loop in `setValue()`; the load's finish handler deleted the dialog under it. Introduced by the M3 demo fix `092dc76`, so it never reached a release. Progress dialogs are now disconnected, cancelled (hidden for good) and deleted later.
- **Selecting n items cost n²:** every per-item `selectionChanged` recomputed the action states over the whole selection. One signal per change now; 1,000 items: select all 361 → 22 ms, longest import stall 305 → 19 ms.
- **Parallel test entries shared one settings file** (and on Windows one registry key); each test process now has its own.

## Known limitations

- On macOS the native menu bar stays visible; Tab and the ≡ button have no effect there.
- Frameless move and resize depend on the compositor; where it refuses, the frame comes back with a notice.
- Window positions are not restored on Wayland (the compositor places windows).
- Opacity is not offered on native Wayland.
- Portable mode (data next to the executable) arrives with the Windows portable ZIP in M5.04.
